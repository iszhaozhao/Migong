# PrivacyMaze 隐私迷宫

赛道：LifeHack 生活娱乐

## 已包含功能

- 6 个独立关卡：位置授权、默认勾选、通讯录邀请、诱导订阅、第三方数据共享、账号注销。
- 每关 3 个不同决策选项，选择后立即出现教育反馈与学习提示。
- 分值累计、进度条、关卡结果回顾与浏览器本地下载 TXT 报告。
- 无账户、无第三方接口、无浏览器存储、无个人数据读取。

## 体验路径

打开页面 → 进入第一关选择权限策略 → 查看反馈 → 连续通关六关 → 阅读报告 → 下载本地报告或重玩。

## 风险与限制

游戏评价以鼓励数据最小化和知情选择为目的，不把某一授权视为永远“违法”或“错误”。每个虚构情境的评分均为游戏性设计，不能代替法律或技术隐私审查。
