# 移动迷宫 · 阶段三 主页面 + 简单/中等模式

浏览器像素风**第一人称**迷宫原型：raycasting 伪 3D 走廊 + 手电筒式局部照明 + 战争迷雾小地图 + 主页面/状态机 + 中等模式局部动态墙。
Vite + TypeScript + HTML Canvas，无游戏引擎、无后端、无外部美术/字体/音频资源（音乐由 Web Audio 实时合成）。

> 本子项目位于仓库 `moving-maze/` 目录，与根目录原有的 PrivacyMaze 单文件原型互不影响。

## 命令

```bash
npm install        # 安装依赖（仅 vite / typescript / @types/node）
npm run dev        # 本地试玩，默认 http://localhost:5173/
npm run build      # tsc 类型检查 + vite 生产构建（产物在 dist/）
npm run preview    # 预览生产构建
npm run validate   # 自动验证：100 张地图 × 生成/自动驾驶/碰撞/迷雾/动态墙 fuzz（54,435 项）
node scripts/validate.ts 500   # 可选：加大地图样本数（61,235 项）
```

带 `?qa=1` 打开（如 `http://localhost:5173/?qa=1`）会暴露 `window.__qa` 调试钩子（相位、会话、动态墙统计、计数器等），普通打开不受影响。

## 主页面与流程

- 主页面只有两个入口：「难度选择」（简单 / 中等可玩，**困难显示开发中且按钮禁用**，不会进入假困难模式）与「快速开始」（恒为简单第 1 关）。
- 相位统一为 `menu / playing / paused / won` 单实例状态机；监听器只注册一次（`counters.listeners` 恒为 22），换关/返回主页面会清理动态墙计时器、特效与按键状态。
- 通关浮层提供「下一关」（同难度、新种子、关卡 +1，不自动升难度或放大地图）与「返回主页面」（清空本局状态）。
- 暂停来源：Esc、鼠标释放、窗口失焦、页面隐藏；都只显示「点击继续探索」，**只有用户点击**才恢复并重新请求鼠标锁定，绝不自动抢鼠标。

## 操作

| 输入 | 行为 |
| --- | --- |
| 点击游戏画面 | 请求 Pointer Lock 锁定鼠标进入鼠标视角 |
| 鼠标移动 | 平滑 yaw + 受限 pitch（地平线偏移，钳制 ±14°） |
| `W` / `S` 或 `↑` / `↓` | 沿当前朝向前进 / 后退（连续坐标，按 dt 移动） |
| `A` / `D` 或 `←` / `→` | 左转 / 右转（无鼠标锁定时仍可玩） |
| `E` | 靠近 + 面向大门且有视线时开门（开门表现播完判定通关，仅一次） |
| `R` / 「重开 (R)」 | 同一张地图重开：位置/朝向/探索/动态墙计时全部重置 |
| `N` | 同难度同关卡换一张新种子地图 |
| `M` / 右上角按钮 | 音乐开 / 音乐关（localStorage 持久化） |
| 「全屏」按钮 | 请求浏览器全屏（被拒绝时忽略，画面本身已铺满视口） |
| `Esc` | 释放鼠标并暂停 |

- 碰撞半径 0.25 格（< 半格），X/Y 分轴检测：不能穿墙、不能切墙角、不能出界；贴墙可沿墙滑动。
- 大 dt 会被钳制并拆成子步（`MAX_SUBSTEP_DISTANCE`），卡顿或切后台回来不会「瞬移穿墙」。
- 点击任何 UI 按钮都不会移动角色、不会抢鼠标。

## 画面、光照与小地图

- 主画面**铺满整个视口**（`position:fixed; inset:0`，无黑边/白边/滚动条）：按整数像素倍率推导低分辨率缓冲（`computeViewLayout`），CSS 尺寸恒为 100% 视口，`image-rendering` 保持像素边缘清晰；resize / fullscreenchange 时重新推导缓冲与投影，几何不变形。
- 视锥 `FOV_DEG = 65`，视距 `VIEW_DISTANCE = 6` 格；pitch 只移动地平线（射线投射伪 3D 的固有限制，不为此重写真 3D 引擎），钳制 ±14° 避免露出空洞。
- 手电筒光照：逐列按与视线夹角衰减（中心亮、边缘暗）× 距离衰减（远处没入纯黑）× 墙面朝向阴影；叠加屏幕暗角；光照使用每条射线的**第一个**命中墙，光不穿墙；近处地板与墙角可读。
- 小地图坐标范围覆盖整张迷宫、固定朝北；只画已探索内容：当前可见更亮、曾探索更暗、未探索不透明纯黑；玩家标记 + 朝向 + **被墙截断的扇形光束**（与第一人称共用 FOV / 视距 / 首个命中墙，64 条射线）；出口只有被看到后才标记；pitch 不影响迷雾记录。
- 中等模式的预警/墙变化若发生在未探索区域，小地图与迷雾**不泄露**；发生在当前视野内才更新记录。

## 大门与环路地图

- 出口是一扇嵌在东边界墙面上的像素大门（门框/门板/门缝光/把手），始终阻挡通行、正确遮挡；门前交互格 `(19,13)` 与西侧固定连接边 `(18,13)` 与门格一起构成**固定保护区**，生成与动态墙都不得改动。
- 地图为 10×7 房间（21×15 墙路网格）随机 DFS 生成后拆除少量内部隔墙形成 5–9 个环路（多条绕行路线），最短路长度限制 30–62；生成后用统一 `validateMaze` 检查（边界封闭、保护区、全房间可达、环路存在、最短路范围），失败有限重试 40 次，再失败使用通过同一套检查的固定模板（`FALLBACK_TEMPLATE`），不会无限循环。
- 简单模式整局地图静态不变。

## 中等模式：局部动态墙

- 每张地图预选 2–3 个「改道模块」（各 2 格内部通道格，一开一闭构成真实绕行切换，曼哈顿跨度 ≤ 4，互不重叠，不碰保护区与外圈）。
- 固定周期 12s 触发一次、一次一个模块：约 2s 可识别的像素预警脉冲（`WARN_RGB` 边缘高亮）+ 约 0.5s 生长/消退动画；所有参数集中在 `config.ts`。
- 事务式切换：先在**副本**上做几何/碰撞/BFS 检查 → 通过才预警 → 预警结束、动画开始前**按玩家最新位置复验**（玩家预警期间移动导致不安全则取消并等下一个周期）→ 动画期间使用两态**并集图**作为唯一有效地图（渲染/碰撞/探索射线读同一引用）→ 结束一次性提交并闪光；并集图不安全时退化为原子切换 + 视觉闪光，绝不出现「画面门开了碰撞没同步」。
- 安全不变量：提交后玩家仍能走到门前交互格；不封闭玩家所在通道、新墙与碰撞体净距 ≥ `PLAYER_RADIUS + DYNAMIC_SAFE_MARGIN`；不压玩家、不开外圈；死胡同可以存在但必须能原路退出。
- 暂停 / 失焦 / 开门表现 / 通关期间动态墙计时与动画冻结；换关/返回主页面 `destroy()` 清空待切换状态与特效。

## 背景音乐

- Web Audio 实时合成（低通低音垫 + 极轻气流噪声 + 稀疏五声音阶铃音），天然循环、音量低（`MUSIC_VOLUME = 0.05`），无外部素材、无许可问题。
- 只在用户首次点击「快速开始 / 选择难度」后创建 AudioContext；创建失败只关闭音乐，不阻止游戏运行。
- 右上角按钮与 `M` 键随时可切换，状态文字 + `aria-pressed` + localStorage 持久化；页面隐藏 suspend、恢复后按原开关状态 resume；换关/返回主页面**不重建**播放器（`createdCount` 恒为 1）。

## 自动验证内容（实际运行结果）

`npm run validate`：**54,435 项检查全部通过**（100 张固定种子地图，退出码 0）；`node scripts/validate.ts 500`：**61,235 项通过**。`npx tsc --noEmit` 无错误；`npm run build` 成功（16 modules，`dist/index.html` 7.48 kB，JS 29.75 kB / gzip 11.96 kB）。

1. **生成（100 种子）**：尺寸/边界/保护区/门几何（门面中心 `(20,13.5)`、法线 `(-1,0)`）、全房间可达、最短路 30–62、环路 5–9；每张图用真实 `Game.update()` 自动驾驶走到门前按 E 开门通关（开门调用恰好 1 次），并跑探索迷雾断言出口被发现、探索比例合理。500 种子统计：最短路 30–62（均值 39.8）、环路 5–9（均值 7.1）、模板回退 0 次、最多重试 3 次、最慢自动驾驶 25.3s。
2. **碰撞与帧率**：撞墙停止不穿墙、0.25s 大 dt ×40 帧不隧穿、45° 贴墙滑动、内墙角不切角（逐帧净距断言）、30fps 与 144fps 同走 1s 位置完全一致、转向按 dt 比例。
3. **pitch 钳制**：双向钳制到 ±`PITCH_MAX` 且不影响位置；改变 pitch 不改变迷雾记录。
4. **大门交互**：手写小图逐条断言——门前/连接边可开、背对/侧向/超角度/超距离不可开；生成图上隔墙直视门面（距离 2.06、角度 0°）因视线被挡不可开；开门表现 720ms 内移动冻结、仅触发一次通关。
5. **迷雾遮挡**：直角走廊图断言墙后/转角后/出口不提前揭示、转弯揭示新区域且旧记录保留、出口标记永久、重置清空；随机图通关后仍有约半数可走格未探索。
6. **observed 快照不透视**：已探索但不在视野的格子，远处地形被替换后记录不变，再次进入视野才更新。
7. **小地图光束**：顶点数 = 射线数 + 1、首顶点为玩家、每顶点 ≤ 视距、不穿墙（`castRay(d-ε)` 为空）、张角恰为 FOV；1920 条随机射线中 1900 条被墙截断。
8. **铺满窗口布局**：10 种视口（320×180 … 3840×2160）整数倍率 ≥1、缓冲×倍率覆盖视口、缓冲 ≤480×300、纵横误差 <2%、小地图格 ≥3 且放得下。
9. **动态墙模块合法性**：30 图 73 模块——内部通道格、一开一闭、跨度 ≤4、互不重叠、不碰保护区、初始状态一致、有效图 = 底图。
10. **事务式切换 fuzz**：30 图 × 6 玩家位置 × 4 周期 = 720 周期；区分「提交」与「复验取消」；预警期地图不变且 ghost 为并集图、动画期 `game.maze === effective`（并集）、提交后恰好 2 格变化、保护区/外圈/碰撞体净距/玩家→门前可达逐条断言、提交后闪光且特效清空、再走 30 帧不卡墙。结果：719 次提交（其中 37 次并集不满足动画安全而原子切换+闪光）、1 次复验取消。
11. **预警后玩家换位**：预警期间把玩家传送到即将闭合的格 → 动画前复验取消、地图不变、玩家未被压住、下一周期仍正常尝试。
12. **预警期间真实移动**：12 图随机走入 + 连续随机输入穿过预警与动画（1956 帧），逐帧断言不压碰撞体、有效图引用一致、玩家→门前可达。
13. **冻结与清理**：暂停/失焦/开门/通关期间 60s 不推进计时；恢复后仍需完整周期；`destroy()` 清空待切换与特效；换关后新实例模块/计时/统计全重置。
14. **迷雾不泄露动态墙**：预警格在进入视野前绝不写入 `observed`；全局不变量 `explored=0 ⇒ observed=未知`、`explored=1 ⇒ observed≠未知`。

- 键盘兜底：`W` 移动；连续 4s 撞墙逐帧 `isFreeAt` 不穿墙；keyup 清空按键。

- 大门与通关：站到门前交互格面向大门 → 提示出现且 `canOpenDoor()` 为真；`E` → 开门表现 → 通关浮层（含用时与探索百分比）。
- 流程与清理：下一关（中等第 2 关、新种子、动态墙统计清零、探索重置）、返回主页面（`dyn=null`、菜单可见）、快速开始（简单第 1 关）；全程 `counters.listeners` 恒为 22、帧计数连续。

## 未验证 / 限制

- **真实 Pointer Lock 手感**：自动化面板拒绝指针锁定（`WrongDocumentError: The root document of this element is not valid for pointer lock`），鼠标视角链路由模拟锁定状态 + 合成移动事件验证；普通桌面浏览器中的真实锁定与手感未在本环境确认。
- **浏览器全屏实际效果**：面板拒绝 `requestFullscreen`（按钮与 try/catch 兜底路径已验证不影响游戏）；铺满视口本身不依赖全屏。
- **真实窗口拖拽 resize**：自动化面板尺寸固定；resize 处理链通过覆盖视口尺寸 + 真实 resize 事件验证，肉眼观感未人工确认。
- **音乐听感**：只验证了 Web Audio 图状态（running/suspended、不叠加、持久化），未验证实际出声与音量听感。
- **pitch 为地平线偏移**：射线投射伪 3D 的固有限制，抬头/低头不会改变墙面透视，仅按 ±14° 偏移地平线。
