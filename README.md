# 移动迷宫 · 阶段二 黑暗中的第一人称像素迷宫

浏览器像素风**第一人称**迷宫原型：raycasting 伪 3D 走廊 + 距离黑暗衰减 + 战争迷雾小地图。
Vite + TypeScript + HTML Canvas，无游戏引擎、无后端、无外部美术/字体/音频资源。
地图在一局内保持不变（静态迷宫）；动态墙、巡逻兵等属于后续阶段，本阶段未实现。

> 本子项目位于仓库 `moving-maze/` 目录，与根目录原有的 PrivacyMaze 单文件原型互不影响。

## 命令

```bash
npm install        # 安装依赖（仅 vite / typescript / @types/node）
npm run dev        # 本地试玩，默认 http://localhost:5173/
npm run build      # tsc 类型检查 + vite 生产构建（产物在 dist/）
npm run preview    # 预览生产构建
npm run validate   # 自动验证：100 张地图自动驾驶 + 碰撞/子步/帧率 + 迷雾遮挡
node scripts/validate.ts 500   # 可选：加大地图样本数
```

## 操作

| 输入 | 行为 |
| --- | --- |
| `W` / `S` 或 `↑` / `↓` | 沿当前朝向前进 / 后退（连续坐标，按 dt 移动） |
| `A` / `D` 或 `←` / `→` | 左转 / 右转（连续角度，按 dt 旋转） |
| `R` 或「重新开始」按钮 | 回到当前地图起点、恢复初始朝向、清空探索记录 |
| `N` 或「新迷宫」按钮 | 生成一张新地图并重置 |
| 「再来一局」按钮 | 通关浮层内，等同「新迷宫」 |

- 碰撞半径 0.25 格（< 半格），X/Y 分轴检测：不能穿墙、不能切墙角、不能出界；贴墙可沿墙滑动。
- 大 dt 会被钳制并拆成子步（`MAX_SUBSTEP_DISTANCE`），卡顿或切后台回来不会「瞬移穿墙」。
- 走到右下角旗帜出口即通关，移动停止并显示「通关成功」浮层。
- 窗口失焦或页面隐藏时暂停并清空按键状态，切回不会自动移动；暂停/缩放**不会**清空已探索区域。

## 画面与小地图

- 主画面：320×180 低分辨率离屏尺寸，CSS 整数倍等比放大（letterbox，不拉伸），`image-rendering: pixelated`；页面/画布/远处环境纯黑。
- 视锥 `FOV_DEG = 65`，视距 `VIEW_DISTANCE = 6` 格；亮度按距离衰减（有限光照，近墙可读、远处没入黑暗）。
- 墙面为程序化低对比像素砖纹，侧面更暗；墙高按垂直距离计算（无鱼眼变形）；地板/天花板为简化渐变。
- 小地图固定右下角（目标约 180×180 CSS px，随窗口自适应），坐标范围覆盖整张迷宫、固定朝北、不滚动。
- 战争迷雾：未探索区域为不透明纯黑，绝不预画墙/路/出口/路线；只揭示**实际看到**的格子。
  - 「当前可见」用更亮颜色，「曾探索但不在视野」用更暗颜色，两套数据分开存储。
  - 揭示规则与主画面共用同一条 DDA 射线（`src/raycast.ts`）：视野锥内逐格揭示走过的地板格与第一面墙，墙后立刻停止。
  - 出生只揭示脚下 + 初始朝向锥；转弯揭示新朝向；出口只有被看到后才在小地图标记并永久保留（本局内）。

## 配置位置

全部可调参数集中在 [src/config.ts](src/config.ts)：

- `ROOMS_X` / `ROOMS_Y`：逻辑房间数（10×7），自动换算为 21×15 的墙/路网格
- `START` / `EXIT`：入口 `(1,1)`、出口 `(19,13)`（列, 行）
- `FOV_DEG` / `VIEW_DISTANCE`：视锥角度与视距（主画面与探索共用）
- `RENDER_W` / `RENDER_H`：低分辨率渲染尺寸（320×180）
- `MOVE_SPEED` / `TURN_SPEED`：移动速度（格/秒）与转向速度（弧度/秒）
- `PLAYER_RADIUS`：碰撞半径（格）
- `MAX_FRAME_DELTA_MS` / `MAX_SUBSTEP_DISTANCE`：dt 钳制与子步上限
- `EXPLORE_RAY_COUNT`：探索迷雾的探测射线数
- `MINIMAP_TARGET_CSS`：小地图目标 CSS 尺寸
- `BRICK_ROWS` / `BRICK_COLS` / `WALL_RGB` / `WALL_SIDE_SHADE` / `FLOOR_RGB`：砖纹与墙/地配色
- `COLORS`：页面、HUD、小地图明暗两套颜色、玩家与出口标记色

## 代码组织

| 文件 | 职责 |
| --- | --- |
| [src/config.ts](src/config.ts) | 尺寸、视锥、速度、碰撞、配色等全部配置 |
| [src/maze.ts](src/maze.ts) | 随机 DFS 生成迷宫、`isWalkable` 统一墙体查询、BFS 可达性与最短路 |
| [src/raycast.ts](src/raycast.ts) | 网格 DDA 射线（主画面渲染与迷雾探索共用，保证遮挡规则一致） |
| [src/game.ts](src/game.ts) | 连续坐标玩家状态：转向、子步移动、分轴碰撞、通关判定（纯逻辑，无 DOM） |
| [src/exploration.ts](src/exploration.ts) | 战争迷雾：`visible` / `explored` 两套数据、出口发现锁存 |
| [src/render.ts](src/render.ts) | 第一人称 raycasting 渲染 + 小地图渲染 |
| [src/main.ts](src/main.ts) | 输入绑定、主循环、HUD、通关浮层、letterbox 缩放 |
| [scripts/validate.ts](scripts/validate.ts) | 自动验证脚本（Node 直接运行 TS） |

墙体/越界查询统一走 `isWalkable(maze, col, row)`，未来加动态墙只需改这一处。
阶段一的 `src/movegate.ts`（逐格移动门控）已删除：移动改为连续坐标 + dt，帧率无关性由子步与 dt 钳制保证。

## 自动验证内容

`npm run validate` 实际执行（非纸面声明），当前 1892 项检查全部通过：

1. 100 张地图：尺寸 21×15、外圈封闭、起终点合法且可走、BFS 可达；并用真实 `Game.update()` 自动驾驶（转向+前进输入）在预算内通关；第 1 张地图同时跑探索迷雾，断言出口最终被发现、探索比例合理。
2. 碰撞与帧率：撞墙停止且不穿墙、0.25s 大 dt 连续 40 帧不隧穿、45° 撞墙沿墙滑动、内墙角分轴检测不切角、30fps 与 144fps 同走 1s 位置完全一致、转向按时间增量比例变化。
3. 迷雾遮挡（固定直角走廊图）：初始朝向不揭示墙后/转角后道路与出口；出生仅揭示初始视野锥；转弯后新区域出现且旧探索保留；出口标记发现后永久保留；重新开始清空探索并回到起点；随机地图通关后仍有未探索区域。

## 已验证 / 未验证

- 已验证（Node）：类型检查、生产构建、上述 1892 项自动验证。
- 已验证（真实浏览器端到端，`?qa=1` 调试钩子 + 真实 KeyboardEvent）：W/S 前进后退、A/D 转向、方向键移动且滚动被拦截、撞墙停止不穿墙、失焦暂停且探索保留、缩放不清探索；自动驾驶按键完整通关（34.1s，探索 63%，「通关成功」浮层出现）；R 重开清空探索/位置/朝向、N 换新图；初始主画面与初始/探索后小地图均导出 Canvas PNG 目视检查（第一人称走廊、近墙可读、远处纯黑；小地图初始仅一小块探索区、探索后显示轨迹且未探索仍为纯黑）。通关浮层的可见性按 computed style 断言：加载时 `display:none`、通关时 `flex`、点击「再来一局」后恢复 `none`（修复过 `.overlay{display:flex}` 覆盖 `hidden` 属性导致浮层常驻的 bug）。
- 未验证：Qoder 内嵌浏览器面板处于隐藏状态（`visibilityState=hidden`），无法原生截屏，画面改为导出 Canvas PNG 检查；隐藏面板会暂停主循环并节流定时器，端到端验证通过把 `requestAnimationFrame` 替换为同步队列驱动帧循环完成（页面加载后需一次 `focus` 事件解除隐藏暂停）。真实可见浏览器中的肉眼手感（按键手感、缩放观感、砖纹观感）未做人工确认。
